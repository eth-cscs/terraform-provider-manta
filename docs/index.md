Use the Manta provider to interact with Manta web service.

Manta dispatches requests to two different possible backend [CSM](https://cray-hpe.github.io/docs-csm/en-15/) and [OpenCHAMI](https://openchami.org/).

~> This Terraform provider still in development and do not only use manta web service as it should, but do request directly to OpenCHAMI.

## Example Usage

```terraform
terraform {
  required_providers {
    manta = {
      source  = "registry.terraform.io/eth-cscs/manta"
      version = ">= 0.0.1"
    }
  }
  required_version = ">= 1.0.0"
}
```
